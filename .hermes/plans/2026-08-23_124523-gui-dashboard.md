# Download Watcher GUI Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a local web dashboard to the existing `dwatcher` engine — live status of the watch loop, move history, category stats, rule editing, and manual controls — served on localhost with a token-protected control API.

**Architecture:** The existing engine (rules → stability → mover → scanner → store → watcher) stays untouched. A new `web` layer wraps it: a threaded stdlib `http.server` serving a single-page dashboard (vanilla JS, no framework, no npm) plus a JSON REST API. The watcher runs in a background thread owned by the server process; all state reads come from the existing SQLite `Store`, so the UI is always consistent with what actually happened.

**Tech Stack:** Python 3.11 stdlib only (`http.server`, `threading`, `json`, `secrets`), vanilla HTML/CSS/JS. Zero new dependencies (per user's install-transparency requirement).

## Proposed Approach

1. **New module `web/server.py`** — `DashboardServer` class: binds `127.0.0.1:8619`, serves `GET /` (dashboard HTML), `GET /api/status`, `GET /api/moves`, `GET /api/stats`, `GET /api/events`, and mutating endpoints `POST /api/scan` (run one scan now), `POST /api/toggle` (pause/resume watcher), `POST /api/rules` (add/remove custom rule). Mutating endpoints require `X-DW-Token` header matching a per-launch token printed to console.
2. **New module `web/static.py`** — embedded assets dict (HTML/CSS/JS as strings) so the package stays single-deployable; written to disk only if customized later (YAGNI now).
3. **Watcher integration** — server owns a `Watcher` in a daemon thread; a `threading.Event` gates scanning (pause/resume); every completed scan updates an in-memory `last_report` for `/api/status`.
4. **CLI wiring** — `python -m dwatcher.cli serve [--port N] [--no-token]` starts server + watcher thread; `serve` becomes the recommended daily-use mode.
5. **Security** (Layer 4/8/9): default bind `127.0.0.1` only; token required for POST endpoints (constant-time compare via `hmac.compare_digest`); token bucket rate limiter (10 POSTs/min/IP) returning `429`; path traversal guard on any file GET (only exact `/` route serves HTML — no file serving at all, so traversal is structurally impossible).
6. **Caching** (Layer 10): `ETag` (md5 of body) + `Cache-Control: max-age=60` on `GET /`; API responses `Cache-Control: no-store`.

```python
"""Token-bucket rate limiting for mutating endpoints."""
import threading


class TokenBucket:
    def __init__(self, capacity: float, refill_per_sec: float, clock=None):
        import time as _time
        self.capacity = float(capacity)
        self.refill = float(refill_per_sec)
        self.clock = clock or _time.monotonic
        self.tokens: dict[str, float] = {}
        self.last: dict[str, float] = {}
        self.lock = threading.Lock()

    def allow(self, key: str) -> bool:
        with self.lock:
            now = self.clock()
            if key not in self.tokens:
                self.tokens[key] = self.capacity
                self.last[key] = now
            elapsed = now - self.last[key]
            self.tokens[key] = min(self.capacity,
                                   self.tokens[key] + elapsed * self.refill)
            self.last[key] = now
            if self.tokens[key] >= 1:
                self.tokens[key] -= 1
                return True
            return False
```

```python
"""Local web dashboard: HTTP API + embedded UI."""
from __future__ import annotations

import hashlib
import json
import secrets
import threading
import time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

from ..store import Store
from .ratelimit import TokenBucket


class _Handler(BaseHTTPRequestHandler):
    server_version = "dwatcher/0.2"

    # -- helpers ----------------------------------------------------------
    @property
    def srv(self):
        return self.server.dwatcher

    def _json(self, payload, status=200, cache="no-store", etag_body=None):
        body = json.dumps(payload).encode()
        self.send_response(status)
        self.send_header("Content-Type", "application/json")
        self.send_header("Cache-Control", cache)
        if etag_body is not None:
            etag = hashlib.md5(etag_body).hexdigest()
            self.send_header("ETag", etag)
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def _client_ip(self):
        return self.client_address[0]

    # -- routes -----------------------------------------------------------
    def do_GET(self):
        srv = self.srv
        if self.path == "/api/status":
            self._json({
                "watching": True,
                "paused": srv.paused.is_set(),
                "uptime_s": round(time.time() - srv.started_at, 1),
                "last_scan": srv.last_scan,
                "token_required": bool(srv.token),
            })
        elif self.path == "/api/moves":
            self._json({"moves": srv.store.recent_moves(limit=50)})
        elif self.path == "/api/stats":
            self._json({"stats": srv.store.stats_by_category()})
        elif self.path == "/":
            self._html_index()
        else:
            self._json({"error": "not found"}, status=404)

    def _html_index(self):
        from .assets import INDEX_HTML
        body = INDEX_HTML.encode()
        etag = hashlib.md5(body).hexdigest()
        if self.headers.get("If-None-Match") == etag:
            self.send_response(304)
            self.send_header("ETag", etag)
            self.send_header("Cache-Control", "max-age=60")
            self.end_headers()
            return
        self.send_response(200)
        self.send_header("Content-Type", "text/html; charset=utf-8")
        self.send_header("Cache-Control", "max-age=60")
        self.send_header("ETag", etag)
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def log_message(self, *a):   # quiet default access log
        pass


class DashboardServer:
    """Owns Store (+ optional Watcher) and serves the dashboard."""

    def __init__(self, watch_dir, dest_root, db, port=8619,
                 token=None, dry_run=False, interval=10, quiet_seconds=30):
        self.watch_dir = watch_dir
        self.dest_root = dest_root
        self.token = token or secrets.token_hex(16)
        self.paused = threading.Event()      # set = paused
        self.started_at = time.time()
        self.last_scan = None
        self.store = Store(db)
        self.interval = interval
        self.quiet_seconds = quiet_seconds
        self.dry_run = dry_run
        self.bucket = TokenBucket(capacity=10, refill_per_sec=10 / 60)
        self._httpd = ThreadingHTTPServer(("127.0.0.1", port), _Handler)
        self._httpd.dwatcher = self
        self.port = self._httpd.server_address[1]

    def start(self):
        t = threading.Thread(target=self._httpd.serve_forever, daemon=True)
        t.start()

    def stop(self):
        self._httpd.shutdown()
        self._httpd.server_close()
        self.store.close()
```

## Risks & Tradeoffs

- **stdlib http.server is not production-grade** — acceptable because bind is localhost-only and the tool is personal; noted in README.
- **Threading**: Store uses one sqlite3 connection shared across threads — mitigate by serializing all Store access through the request handler thread with a `threading.Lock` in `Store` (small change, add `check_same_thread=False` + lock). *Include in Task 2.*
- **Port conflict on 8619** — `--port 0` supported; launcher uses fixed port, document fallback.
- **Token UX friction** — `--no-token` escape hatch documented but discouraged.
- **YAGNI guards**: no WebSocket/SSE (polling suffices), no external JS framework, no HTTPS (localhost), no rule-editing POST yet (stub display only) — defer until wanted.
